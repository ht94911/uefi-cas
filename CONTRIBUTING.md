# Contributing to cas firmware

[简体中文](CONTRIBUTING.zh-CN.md) · [Project home](https://github.com/ht94911/UniXNU-cas)

Use the [cas contribution guide](https://github.com/ht94911/UniXNU-cas/blob/main/CONTRIBUTING.md)
for source ownership, validation and reporting. Firmware code belongs here;
device/OS configuration and public project documentation live in UniXNU-cas.

Preserve upstream notices and the immutable hardware-tested tag. New image bytes
need new applicable validation. Do not publish vendor firmware or device-specific
private evidence. Use the cas build guide rather than generic upstream setup scripts.
Report issues through the [main project](https://github.com/ht94911/UniXNU-cas/issues).
